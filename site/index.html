Install or set up Wi-Fi

This browser can't talk to USB devices. Use Chrome or Edge on a computer. This page must be opened over https.

Plug the watch into this computer with a USB-C data cable, click Connect watch, and pick the watch's port (USB JTAG/serial debug unit).

First install

  1. Click Connect watch and choose Install Electric Pocket Watch.
  2. When it finishes, the page asks for your Wi-Fi network and password. The watch joins once, sets its clock, and turns Wi-Fi off again.

Use a 2.4 GHz network. Installing again erases the saved Wi-Fi.

Change Wi-Fi later

On the watch: Settings → Wi-Fi, pick a network, type the password. Or from this page:

  1. Plug the watch in and click Connect watch.
  2. Choose Change Wi-Fi (or Connect to Wi-Fi) and enter the network.

On the watch

  1. Wake: press BOOT or PWR, or double-tap the case.
  2. Change face: press BOOT or swipe.
  3. Settings: double-press BOOT or swipe up. Wi-Fi, set time, open Wi-Fi, dial theme.
  4. Set the time: hold BOOT for a second while the screen is on.
  5. Screen off: press PWR. Holding PWR for several seconds powers the watch off.
