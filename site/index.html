Plug the watch into this computer with a USB-C data cable, click its button, and pick the watch's port (USB JTAG/serial debug unit). Firmware for a different board will not run correctly; if the screen stays dark after installing, check the board name and install again.

First install

  1. Click your board's button and choose Install Electric Pocket Watch.
  2. When it finishes, the page asks for your Wi-Fi network and password. The watch joins once, sets its clock, and turns Wi-Fi off again.

Use a 2.4 GHz network. Choosing erase during install also erases the saved Wi-Fi and the battery log.

Change Wi-Fi later

On the watch: Settings → Wi-Fi → Choose network, pick one, type the password. Or from this page:

  1. Plug the watch in and click your board's button.
  2. Choose Change Wi-Fi (or Connect to Wi-Fi) and enter the network.

On the watch

  1. Wake: press BOOT or PWR, or double-tap the case.
  2. Change face: press BOOT or swipe.
  3. Settings: double-press BOOT or swipe up. Wi-Fi (status, networks, set time), Display (brightness, screen-on time, on while charging), System (battery, log, restart).
  4. Set the time: hold BOOT for a second while the screen is on.
  5. Screen off: press PWR. Power off: hold PWR for 3 seconds; press PWR or plug in USB to turn it back on.

The 1.75 / 1.75-B and 2.06 have a battery-backed clock chip, so they keep the time while powered off. The 1.75C sets its clock over Wi-Fi after each power-on.
